# 🤖 AI Chatbot UI

![Chatbot interface illustration](https://images.unsplash.com/photo-1531746790731-6c087fecd65a?auto=format&fit=crop&w=1200&q=80)

This project is a modern chatbot-style user interface built using HTML, CSS, and JavaScript. It simulates a conversation experience with a responsive layout and interactive message area.

## 🌟 Overview

The app focuses on creating a polished chatbot frontend with:

- message bubbles
- user and bot styling
- conversation layout
- animated, modern interface

## ✨ Features

- 💬 Chat panel interface
- 🧑‍💻 User and assistant message styling
- 🎨 Clean and modern design
- 📱 Responsive layout
- ⚡ Lightweight front-end project

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📁 Project Structure

```text
Chatbot/
├── index.html

├── ai_chatbot.js

```

## ▶️ Run the Project

Open `index.html` in the browser, or use a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
